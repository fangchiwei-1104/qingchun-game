# 青春情誼園遊會

健康教育（健體 3 上）單元 2・第 1 章「青春情誼」的分支角色扮演遊戲。

- **三個劇本**：轉學生小君的園遊會、園遊會的衝突、我訊息修復友誼
- **五大人格特質**：每個選擇有 5 個選項，分別對應 O 開放性、C 盡責性、E 外向性、A 親和性、N 情緒敏感（神經質）
- **沒有標準答案**：選擇會改變人際關係數值，數值再影響後續事件與結局的機率
- **結局後**：分析人格傾向，並對應課本內容（增進人際關係策略、衝突解決、我訊息）給出總體建議

整個遊戲只有 `index.html` 一個檔案，用瀏覽器打開即可遊玩。學生的結局收集與反思作答只存在自己裝置的瀏覽器中。
