6-1 板塊間的相對運動

課本 P168–170、P188–189
🎯 分辨板塊分離與板塊聚合各會形成什麼地形與地質活動；說明海洋板塊為什麼會隱沒。
🤔 板塊被「拉開」和被「擠壓」，地表會長出不一樣的東西嗎？
  1. 板塊＝岩石圈分裂成的大小區塊，在軟流圈上緩慢移動（地函熱對流帶動）。
  2. 拉開（張裂力）→ 中間變薄、下陷、岩漿湧出 → 中洋脊／裂谷。
  3. 擠壓（聚合）→ 密度大的往下隱沒 → 海溝、火山；兩大陸相撞 → 造山運動、褶皺。
  4. 不論分離或聚合，岩層都可能斷裂 → 都會有地震。

📍 震源・震央・震源深度 互動圖

🤔 「震央」在地底下還是地表上？斷層裂到地表的地方就是震央嗎？
  1. 震源：岩層最先斷裂、引發地震的位置（在地下）。
  2. 震央：震源垂直投影到地表的位置（在地表，正上方）。
  3. 震源深度：震源到震央的垂直距離。斷層出露地表的地方，不一定在震源正上方！
  4. 測站、震央、震源三點構成直角三角形 → 用畢氏定理求距離。
震源深度 h：20 km
測站到震央距離（震央距）s：40 km

🛟 地震來了怎麼辦？（P175、P186–187）

・室內：趴下、掩護、穩住；不要急著奪門而出（公共場所更容易推擠受傷），不搭電梯。
・強震即時警報：利用電磁波傳播速率遠快於地震波，在地震「發生後」搶先通知；不是地震預測。離震央近的地方可能來不及收到預警。
・地震不一定引發海嘯；新聞中的損失要看清楚是什麼原因造成（例如海底電纜斷裂，而非海嘯）。

6-3 岩層與地質事件

課本 P180–181
🎯 運用三個判斷原則，排出岩層中地質事件的先後順序，並推論岩脈或岩層的年代範圍。

① 水平沉積

沉積岩在不受外力時，通常呈接近水平。
👉 看到傾斜或彎曲的岩層 → 表示後來受過力。

② 下老上新（疊置）

未倒轉的岩層：下方先沉積、較老；上方後沉積、較新。

③ 切入者較新（截切）

較早的事件會被較晚的事件影響：
被切穿的較老、切穿別人的較新（岩脈、斷層、侵蝕面都適用）。
🤔 岩脈切穿了 X 層，卻被上面的 Y 層蓋住，岩脈的年代介於哪裡？
  1. 岩脈切穿 X → 岩脈比 X 晚形成（X 先存在，才能被切）。
  2. Y 覆蓋在岩脈上、沒有被切 → 岩脈比 Y 早形成。
  3. 所以：X 形成之後 ＜ 岩脈 ＜ Y 形成之前。若知道 X、Y 的年代，就能夾出岩脈的年代範圍。

6-3 岩層與化石

課本 P182–183
🎯 判斷什麼是化石；用化石推論岩層的沉積環境與地質年代；知道地質年代如何劃分。

🦴 化石是什麼？

古代生物死亡後，其遺骸（骨骼、外殼、整個生物體）或遺跡（足跡、爬痕、巢穴、排遺）被泥沙等沉積物掩埋，極少數被保留下來 → 化石。
・化石通常保存在沉積岩中。
・不是化石：礦物結晶（如水晶）、現代生物的殼、模型。
・用途：判斷岩層的沉積環境（海洋／陸地）與形成年代。

統整與自評

課本 P184–185 圖解point
🎯 用一張圖串起整章；檢查自己的易錯點。

6-1 地球的構造

  • 分層依據：地震波波速變化
  • 地殼（陸：花岡岩／海：玄武岩）→ 地函（氧矽鎂）→ 地核（鐵鎳）
  • 密度：陸殼＜洋殼＜地函＜地核
  • 岩石圈＝地殼＋部分地函（板塊）；軟流圈在地函中、可塑

6-1 板塊運動

  • 分離（張裂）：中洋脊、裂谷、新地殼（玄武岩）；離脊愈遠愈老
  • 聚合（擠壓）：海溝、隱沒、火山、造山、褶皺
  • 兩者皆有：地震、斷層、火山
  • 密度大的板塊隱沒

6-2 內營力

  • 褶皺＝彎曲（擠壓、深處）；斷層＝斷裂（正、逆、平移）
  • 震源（地下）→ 震央（正上方地表）；震源深度＝垂直距離
  • 規模＝能量、一次一值、無單位；震度＝搖晃程度、0～7級

6-2 臺灣

  • 歐亞板塊＋菲律賓海板塊；交界花東縱谷
  • 菲律賓海板塊每年7～8 cm向西北推擠
  • 北：菲律賓海板塊隱沒；南：歐亞板塊隱沒
  • 證據：斷層、地震、火山群、褶皺山脈、溫泉噴氣孔

6-3 岩層

  • 水平沉積、下老上新、切人者較新
  • 岩脈：比被切穿的晚、比覆蓋它的早

6-3 化石

  • 遺骸＋遺跡；多在沉積岩
  • 古生代三葉蟲／中生代恐龍、菊石／新生代哺乳類
  • 地質年代依化石種類＋重要地質事件劃分

⚠️ 易錯十大

  1. 分層依據是地震波波速，不是岩石種類或溫度。
  2. 海洋地殼薄但密度大；岩石圈不只地殼。
  3. 聚合不會形成中洋脊；分離不會形成褶皺。
  4. 最古老的海洋地殼離中洋脊最遠。
  5. 震央在震源正上方，不是斷層出露處。
  6. 震度大 ≠ 能量大；離震央近 ≠ 規模大。
  7. 規模沒有單位；震度用「級」。
  8. 交界是花東縱谷不是中央山脈；北菲律賓海隱沒、南歐亞隱沒。
  9. 海蝕、沙灘等是外營力，不能證明板塊交界。
  10. 足跡、排遺、琥珀中的昆蟲也是化石；水晶不是。
