# 第6章 板塊運動與岩層的祕密｜學生個人版

學生可獨立操作原版互動模擬、做單元練習，再進入「個人測驗與成績」。個人測驗共 15 題，三個單元各抽 5 題。交卷後顯示百分制、各單元答對題數與錯題解析。瀏覽器允許本機儲存時，同一裝置可續做。

## 教師設定成績收件

1. 開啟 [Google Apps Script](https://script.google.com/)，建立新專案並以此目錄的 `Code.gs` 取代預設程式碼。
2. 在編輯器執行一次 `setupScoreReceiver` 並授權。執行記錄會顯示教師的成績試算表網址與學生用上傳代碼。成績表由執行設定的帳號持有，請維持限制存取。
3. 選擇「部署 → 新增部署 → 網頁應用程式」。執行身分選自己的帳號，存取權使用學生可連線的設定。無 Google 帳號的學生需要「任何人」選項，若校方帳號限制此選項，請使用學校核准的收件設定。收件代碼填入學生頁面後，才可送出成績。
4. 在 `index.html`（下載版本為 `Geology-Student.html`）把 `const SCORE_ENDPOINT = '';` 的引號內填入第 3 步取得的 Apps Script `/exec` 網址，再提交到 GitHub。學生頁面不需要填入試算表 ID 或管理憑證。
5. 以測試用班級與座號完成一次測驗，確認 Google 收件分頁顯示「成績已收到」，並在成績表核對資料。用同一份測驗重送一次應維持同一列。
6. 上傳代碼可在 Apps Script 專案設定的指令碼屬性中更換 `SCORE_UPLOAD_CODE`，允許英數字 6–16 碼。學生網頁會在收件端尚未設定時提供成績下載。

收件表記錄時間、班級、座號、答對題數與各單元結果。上傳只在學生主動送出表單時發生。收件頁在新分頁顯示結果，學生可以回到原頁重送。此流程供平時複習使用，班級座號由學生自行填寫。公共網頁的複習題庫含答案。

## GitHub Pages

新儲存庫建議將 `index.html` 放在 `main` 分支根目錄，然後在 **Settings → Pages** 設為 **Deploy from a branch → main → /(root)**。若放在已啟用的 GitHub Pages 儲存庫子目錄，使用該子目錄的發布網址。
