# 701 班自然第 2 章《養分》

學生頁面 https://fangchiwei-1104.github.io/qingchun-game/biology-701-nutrition/

每小節隨機抽 10 道不重複題目，答對 6 題即達標。低於 60 分時，學生先回到原小節複習，然後保留上一輪 5 題，從上一輪未出現的題目中隨機抽 5 題。各次成績以不同測驗編號提交。

## 啟用教師收件

1. 開啟 [現有的 Apps Script 專案](https://script.google.com/home/projects/1tqEYDJi0RDm6WirLZA5kMAocRagsvgGtYhhOUUFAiERujy_JJf6l2pft/edit)，在編輯器把現有程式碼更新成 [同一儲存庫的 Code.gs](../geology-review/Code.gs) 全文，再儲存。更新已沿用原本的收件配置，直接使用現有試算表和上傳代碼。執行初始化函式並非此更新所需。
2. 選「部署」→「管理部署作業」→原部署的「編輯」→「版本」選「建立新版本」→「部署」。這個動作沿用原來的收件網址。
3. 重新整理學生頁面，完成一次小節測驗。出現「上傳成績」後，填入座號與原本的上傳代碼，即可測試。試算表在首次成功收件時會新增「701生物第2章成績」分頁。

網頁會在現有收件網址支援本章後顯示上傳按鈕。部署前，學生仍可完成測驗並下載成績。
