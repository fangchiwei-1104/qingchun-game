3-1 莖的維管束排列、樹皮與年輪

課本 P90–93
🎯 分辨環狀排列（有形成層）與散生排列；了解形成層如何讓莖加粗；解釋樹皮、木材、年輪，以及樹皮被環剝為什麼會死。

📌 兩種排列

環狀排列散生排列
例子向日葵、榕樹、朱槿、樹木玉米、水稻、竹子、椰子
形成層有（木質部與韌皮部之間）通常沒有
莖加粗可以逐年加粗不會逐年加粗

・形成層：細胞分裂，向內產生新木質部、向外產生新韌皮部 → 莖加粗
・由內而外：老木質部 → 新木質部 → 形成層 → 新韌皮部 → 老韌皮部 → 表皮
・樹皮＝韌皮部及其外圍；木材＝堆積的（老）木質部
・年輪：春夏細胞大、色淺；秋冬細胞小、色深；四季分明的地方年輪最明顯

🌳 年輪產生器

樹齡：6 年

🐿️ 為什麼「環剝樹皮」會死，「樹幹中空」卻能活？

・樹皮含韌皮部 → 被啃一圈 → 葉製造的養分送不到根 → 根細胞缺養分死亡 → 根無法吸水 → 枝葉缺水枯死。
・神木中心是不具運輸功能的老化木質部，外圍仍有新木質部運輸水分 → 中空也能活。

3-2 植物體內的養分與水分運輸

課本 P94–99
🎯 描述養分（韌皮部）與水分（木質部）的運輸方向；說明根毛、蒸散作用與保衛細胞的角色。

📌 重點

・養分（韌皮部）：由供應部位 → 需求或儲存部位，可由上而下，也可由下而上（例：木棉落葉後，春天用根部儲存的養分開花）
・水分＋礦物質（木質部）：由下往上；根毛增加吸收面積，水以滲透作用進入根
・蒸散作用：水變成水蒸氣由氣孔散失 → 把木質部中的水向上拉升 → 水分上升的主要動力
・氣孔：水蒸氣、氧氣、二氧化碳的通道（不吸收水分）；保衛細胞吸水膨脹 → 張開；失水 → 關閉
・通常白天張開、晚上關閉；乾燥缺水時白天也會關閉

動脈微血管靜脈

3-3 血液循環：體循環與肺循環

課本 P106–107
🎯 依序說出體循環與肺循環的路徑；判斷哪裡是充氧血／缺氧血；描述組織與肺部的氣體交換。

🔁 血液循環動畫（點編號看說明）

🔴 充氧血（氧氣多）　🔵 缺氧血（二氧化碳多）
體循環和肺循環同時進行，在心臟交會。

📌 路徑口訣

體循環：❶左心室 → ❷主動脈 → ❸小動脈 → ❹全身組織微血管（O₂ 給細胞、CO₂ 進血液）→ ❺小靜脈 → ❻上、下大靜脈 → ❼右心房
肺循環：❽右心室 → ❾肺動脈 → ❿肺部微血管（CO₂ 到肺泡、O₂ 進血液）→ ⓫肺靜脈 → ⓬左心房
左心（左心房、左心室）、主動脈、肺靜脈 → 充氧血；右心、上下大靜脈、肺動脈 → 缺氧血
⚠️ 名稱和血液種類「相反」的兩條：肺動脈流缺氧血、肺靜脈流充氧血。

3-3 淋巴系統

課本 P108–109
🎯 說明血漿 → 組織液 → 淋巴 → 靜脈的流動；知道淋巴結的功能。

📌 重點

・人體循環系統＝心血管系統＋淋巴系統
・淋巴系統：淋巴器官（淋巴結）、淋巴管、淋巴
・血漿的「部分物質」從微血管滲出 → 組織液 → 滲入淋巴管 → 淋巴 → 最後注入靜脈
・組織液、淋巴不含紅血球（紅血球太大，留在血管內）
・淋巴管有瓣膜防逆流
・功能：維持血液組成恆定；淋巴結過濾病原體與異物，有白血球作用 → 感染時淋巴結腫大（如扁桃腺發炎）

3-4 人體的防禦作用與疫苗

課本 P114–117、P124–125
🎯 分辨三道防禦：①皮膜阻隔 ②吞噬與發炎（非專一性）③專一性防禦；說明疫苗利用記憶性。

📌 三道防禦

防禦內容專一性？
① 皮膜的阻隔皮膚、黏膜（眼、口、鼻、消化道…）阻擋；淚液、黏液；胃的鹽酸、消化酵素❌ 非專一性
（對所有病原體）
② 吞噬作用與發炎反應白血球吞噬病原體；紅、熱、腫、痛使白血球大量聚集
③ 專一性防禦特殊白血球：破壞被感染的細胞、產生抗體；具記憶性✅ 專一性
（只對特定病原體）
⚠️ 胃酸殺菌屬於①皮膜阻隔，不是吞噬作用。⚠️ 吞噬病原體的是白血球，不是紅血球。⚠️ 疫苗是「預防」，不是治療。

重點整理與自評

課本 P118–119
🎯 檢查各小節的易錯觀念，完成自評後可下載自己的學習紀錄。

⚠️ 易錯十大

  1. 葉：木上韌下；莖：木內韌外。
  2. 樹皮＝韌皮部及其外圍；木材＝老化木質部。
  3. 形成層：向內生木質部、向外生韌皮部；散生排列（玉米、水稻、竹）沒有。
  4. 年輪：秋冬細胞小、顏色深；四季分明才明顯。
  5. 養分可上可下；水分由下往上，動力是蒸散作用。
  6. 氣孔不吸收水分；保衛細胞吸水 → 氣孔打開。
  7. 肺動脈流缺氧血、肺靜脈流充氧血。
  8. 白血球最大、有核；紅血球最多、運氧；血小板最小、凝血。
  9. 組織液、淋巴不含紅血球；淋巴最後注入靜脈。
  10. 胃酸＝第一道；發炎、吞噬＝第二道（非專一）；抗體＝第三道（專一、記憶）。
